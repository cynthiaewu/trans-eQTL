# Trex-QTL

This repository contains the following utilities for simulating expression datasets and running various methods for trans-eQTL detection:

* [`trexqtl-simulate`](simulate/README.md): Tool for simulating expression datasets for a cohort of individuals
* [`trexqtl-run`](trexqtl/README.md): Tool for detecting trans-eQTL using either the published CPMA method or our new mixture model based method (Trex-QTL). 

# Install

To install Trex-QTL locally, run:

```
python3 setup.py install --user
```

This will install the commands `trexqtl-simulate` and `trexqtl-run`. Type `trexqtl-simulate --help` or `trexqtl-run --help` for usage information.

# Quick Start

An example dataset is provided in `example` to demonstrate the complete Trex-QTL workflow.

The folder contains:

```
example/
├── genotypes.csv
├── expression.csv
├── betas.csv
├── matrixeqtl_out
└── trexQTL_out/
    └── results.tab
```

where:

- `genotypes.csv` – simulated SNP genotypes
- `expression.csv` – simulated gene expression
- `betas.csv` – simulated SNP effect sizes
- `matrixeqtl_out` – SNP–gene association statistics generated by Matrix eQTL
- `trexQTL_out/` – example Trex-QTL and CPMA results

## Running Trex-QTL on the example dataset

To verify your installation, simply run:

```bash
trexqtl-run \
    --input example/matrixeqtl_out \
    --out example_output \
    --trexqtl \
    --cpma \
    --null_method chi2
```

The output should match the files in:

```
example/trexQTL_out/
```

## Regenerating the example dataset

The example dataset was generated using:

```bash
trexqtl-simulate \
    --num-genes 100 \
    --num-samples 150 \
    --num-snps 10 \
    --num-nullsnps 90 \
    --num-targets 10 \
    --beta 0.5 \
    --out example
```

The SNP–gene association statistics were then computed using Matrix eQTL:

```bash
Rscript Run_Matrix_eQTL_PC_PEER_quantile_norm.r \
    -g genotypes.csv \
    -e expression.csv \
    -o matrixeqtl_out \
    -d ','
```

Finally, Trex-QTL was run using:

```bash
trexqtl-run \
    --input matrixeqtl_out \
    --out trexQTL_out \
    --trexqtl \
    --cpma \
    --null_method chi2 \
    --threads 1
```
